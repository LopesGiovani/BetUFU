## Trust Boundaries

| Boundary | Description |
|---|---|
| Generated BFF capabilities response -> Angular adapter | Server-provided navigation metadata crosses into an untrusted, stale-capable client. |
| Angular guard/menu -> product navigation | Client routing and visibility can improve UX but cannot authorize an operation. |
| Angular operation page -> BFF operation endpoint | The BFF 403 is authoritative even after a permissive or stale client render. |
| Session termination response -> user-facing chrome | The server intentionally withholds the cause; client inference could disclose or fabricate security information. |
| Build route source -> validator | Tampered route composition could bypass the completion guard or expose development-only destinations. |
