```powershell
function ConvertTo-BetufuNativeArgument {
  param([AllowEmptyString()][string]$Value)

  if ($Value.Length -gt 0 -and $Value -notmatch '[\s"]') {
    return $Value
  }

  $builder = New-Object System.Text.StringBuilder
  [void]$builder.Append('"')
  $backslashes = 0
  foreach ($character in $Value.ToCharArray()) {
    if ($character -eq '\') {
      $backslashes++
      continue
    }
    if ($character -eq '"') {
      [void]$builder.Append(('\' * (($backslashes * 2) + 1)))
      [void]$builder.Append('"')
      $backslashes = 0
      continue
    }
    if ($backslashes -gt 0) {
      [void]$builder.Append(('\' * $backslashes))
      $backslashes = 0
    }
    [void]$builder.Append($character)
  }
  if ($backslashes -gt 0) {
    [void]$builder.Append(('\' * ($backslashes * 2)))
  }
  [void]$builder.Append('"')
  return $builder.ToString()
}
```

```powershell
function Get-BetufuSanitizedRuntimeFailure {
  param([Parameter(Mandatory = $true)][string]$StandardError)

  $runtimeErrorLines = @(
    $StandardError -split '\r?\n' |
      Where-Object { $_.Trim() -ne '' }
  )
  if ($runtimeErrorLines.Count -ne 1 -or
      $runtimeErrorLines[0].Length -gt 600) {
    return $null
  }
  $runtimeErrorMatch = [regex]::Match(
    $runtimeErrorLines[0],
    '^\[validate-runtime-prerequisites\] ERRO: ' +
      '(RUNTIME_[A-Z0-9_]{1,64}): ' +
      '([\p{L}\p{Nd} .,_:;()/=@+\-]{1,512})$'
  )
  if (-not $runtimeErrorMatch.Success) {
    return $null
  }
  return ($runtimeErrorMatch.Groups[1].Value + ': ' +
    $runtimeErrorMatch.Groups[2].Value)
}

function Get-BetufuServiceSnapshot {
```

O bloco material completo está abaixo. Ele mantém um lock local exclusivo e, sob janela humana sem operação Docker paralela, opera somente os IDs congelados. A ordem preserva a dependência real: PostgreSQL é iniciado, se necessário, e precisa ficar `healthy` antes de qualquer start do Keycloak; só então o Keycloak é iniciado e aguardado. Não há `compose up`, criação ou recriação. O runner possui deadline interno de 180 segundos, até 30 segundos de verificação final e até 90 segundos para três cleanups sequenciais; o wrapper externo dá 330 segundos para que o próprio runner finalize antes de considerar o processo travado. O stdout do runner deve conter exatamente uma linha JSON sanitizada e stderr deve permanecer vazio. O SQL via única exceção `sh -e`/stdin fixa Unix socket, limpa variáveis `PG*` que poderiam redirecionar a conexão e usa `--no-password`: autenticação TCP por senha já é provada pelo backend; esta consulta prova a role e suas permissões sem colocar senha no argv. `PGOPTIONS` limita cada statement e o timeout externo limita o processo cliente.

```powershell
$primaryFailure = $null
$cleanupFailures = New-Object System.Collections.Generic.List[string]
$betufuRuntimeEvidence = $null
$betufuRuntimeFailureMarker = $null
$startedSnapshots = @{}
$startAttempts = @{}
$finalSnapshots = @{}
$runtimeLockPath = Join-Path (Get-Location).Path 'backend/target/01-29-runtime.lock'
$runtimeLock = [IO.File]::Open(
  $runtimeLockPath,
  [IO.FileMode]::CreateNew,
  [IO.FileAccess]::ReadWrite,
  [IO.FileShare]::None
)

try {
  # O lock coordena somente execuções cooperativas deste protocolo. A janela material
  # exige exclusividade humana: ninguém opera o projeto Compose em paralelo.
  foreach ($service in $targetServices) {
    $beforeStart = Get-BetufuServiceSnapshot -Service $service
    $initial = $initialSnapshots[$service]
    if ($beforeStart.Id -cne $initial.Id -or
        $beforeStart.State -cne $initial.State -or
        $beforeStart.StartedAt -cne $initial.StartedAt -or
        $beforeStart.Image -cne $initial.Image) {
      throw ('Estado mudou antes da operação exata: ' + $service + '.')
    }
    if ($initial.State -eq 'exited') {
      [void]$servicesStartedByBlock.Add($service)
      $startAttempts[$service] = [DateTimeOffset]::UtcNow
      $startResult = Invoke-BetufuProcess -FilePath $dockerPath `
        -ArgumentList @('container', 'start', $initial.Id) `
        -TimeoutMilliseconds 60000
      Assert-BetufuExitZero -Result $startResult -Label ('Start exato ' + $service)
      $afterStart = Get-BetufuServiceSnapshot -Service $service
      if ($afterStart.Id -cne $initial.Id -or
          $afterStart.Image -cne $initial.Image -or
          $afterStart.State -cne 'running' -or
          $afterStart.StartedAt -ceq $initial.StartedAt -or
          [DateTimeOffset]::Parse($afterStart.StartedAt) -lt $startAttempts[$service]) {
        throw ('Start não produziu fingerprint atribuível: ' + $service + '.')
      }
      $startedSnapshots[$service] = $afterStart
      $expectedStartedAt = $afterStart.StartedAt
    } else {
      $expectedStartedAt = $initial.StartedAt
    }

    $healthDeadline = [DateTimeOffset]::UtcNow.AddSeconds(600)
    do {
      $healthySnapshot = Get-BetufuServiceSnapshot -Service $service
      if ($healthySnapshot.Id -cne $initial.Id -or
          $healthySnapshot.Image -cne $initial.Image -or
          $healthySnapshot.State -cne 'running') {
        throw ('Serviço não ficou running sem substituição: ' + $service + '.')
      }
      if ($healthySnapshot.StartedAt -cne $expectedStartedAt) {
        throw ('Fingerprint do serviço mudou durante a espera: ' + $service + '.')
      }
      $serviceHealthy = $healthySnapshot.Health -ceq 'healthy'
      if (-not $serviceHealthy) {
        if ($healthySnapshot.Health -in @('unhealthy', 'none')) {
          throw ('Health incompatível com o contrato: ' + $service + '.')
        }
      }
      if (-not $serviceHealthy -and
          [DateTimeOffset]::UtcNow -ge $healthDeadline) {
        throw ($service + ' não ficou healthy em 600 segundos.')
      }
      if (-not $serviceHealthy) {
        Start-Sleep -Seconds 1
      }
    } while (-not $serviceHealthy)

    if ($service -eq 'postgres' -and $healthySnapshot.Health -cne 'healthy') {
      throw 'PostgreSQL precisa estar healthy antes do Keycloak.'
    }
  }

  $runtimeArguments = @(
    'scripts/validate-runtime-prerequisites.mjs', '--runtime',
    '--expected-jar-sha256',
    '15D7514BF98EE415D0FC83E6008AE0838ACBD01EE17CB53B09B3ABF33A5A0878',
    '--expected-jar-size', '78665537'
  )
  $runtimeResult = Invoke-BetufuProcess -FilePath $nodePath `
    -ArgumentList $runtimeArguments -TimeoutMilliseconds 330000
  $betufuCommandExitCodes['Runner runtime'] = $runtimeResult.ExitCode
  if ($runtimeResult.ExitCode -ne 0) {
    $betufuRuntimeFailureMarker = Get-BetufuSanitizedRuntimeFailure `
      -StandardError $runtimeResult.Stderr
    if ($null -eq $betufuRuntimeFailureMarker) {
      throw ('Runner runtime falhou com código ' + $runtimeResult.ExitCode +
        ' e stderr fora da allowlist sanitizada.')
    }
    throw ('Runner runtime falhou: ' + $betufuRuntimeFailureMarker + '.')
  }
  if ($runtimeResult.Stderr -cne '') {
    throw 'Runner runtime emitiu stderr inesperado.'
  }
  $runtimeLines = @(
    $runtimeResult.Stdout -split '\r?\n' | Where-Object { $_.Trim() -ne '' }
  )
  if ($runtimeLines.Count -ne 1) {
    throw 'Runner runtime não emitiu exatamente uma linha JSON.'
  }
  try {
    $betufuRuntimeEvidence = $runtimeLines[0] | ConvertFrom-Json -ErrorAction Stop
  } catch {
    throw 'Runner runtime emitiu JSON inválido.'
  }
  $runtimePropertyNames = @(
    $betufuRuntimeEvidence.PSObject.Properties.Name | Sort-Object
  )
  $expectedRuntimePropertyNames = @(
    'browserExposure', 'cleanup', 'csrf', 'identityUuid', 'jarSha256',
    'jarSize', 'jarHashBefore', 'jarHashAfter', 'jarSizeBefore',
    'jarSizeAfter', 'java', 'loginFlow', 'ownedProcesses',
    'proxyEvidence', 'redis', 'status', 'statuses'
  ) | Sort-Object
  if (($runtimePropertyNames -join "`n") -cne
      ($expectedRuntimePropertyNames -join "`n")) {
    throw 'Schema da evidência JSON runtime divergiu da allowlist.'
  }
  $betufuRuntimeIdentityUuid = [string]$betufuRuntimeEvidence.identityUuid
  if ($betufuRuntimeEvidence.status -cne 'ok' -or
      $betufuRuntimeEvidence.jarSha256 -cne
        '15D7514BF98EE415D0FC83E6008AE0838ACBD01EE17CB53B09B3ABF33A5A0878' -or
      [int64]$betufuRuntimeEvidence.jarSize -ne 78665537 -or
      $betufuRuntimeEvidence.jarHashBefore -cne
        '15D7514BF98EE415D0FC83E6008AE0838ACBD01EE17CB53B09B3ABF33A5A0878' -or
      $betufuRuntimeEvidence.jarHashAfter -cne
        '15D7514BF98EE415D0FC83E6008AE0838ACBD01EE17CB53B09B3ABF33A5A0878' -or
      [int64]$betufuRuntimeEvidence.jarSizeBefore -ne 78665537 -or
      [int64]$betufuRuntimeEvidence.jarSizeAfter -ne 78665537 -or
      $betufuRuntimeIdentityUuid -notmatch
        '^[0-9a-f]{8}-[0-9a-f]{4}-[1-5][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$') {
    throw 'Evidência JSON runtime divergiu do contrato aprovado.'
  }

  $postgresProofInput = @'
unset PGHOST PGPORT PGSERVICE PGSERVICEFILE PGOPTIONS PGPASSWORD
export PGOPTIONS='-c statement_timeout=15000'
exec psql --host /var/run/postgresql --port 5432 --username "$BETUFU_DB_USER" --dbname "$BETUFU_DB_NAME" --no-password --set ON_ERROR_STOP=1 --quiet --tuples-only --no-align <<'BETUFU_SQL'
\set runtime_identity_uuid '__BETUFU_RUNTIME_UUID__'
SELECT CASE WHEN
  current_setting('server_version_num')::integer / 10000 = 18
  AND current_database() = 'betufu_local'
  AND current_user = 'betufu_app'
  AND (SELECT count(*) FROM public.flyway_schema_history
       WHERE version = '1' AND success IS TRUE) = 1
  AND (SELECT count(*) FROM public.local_identity
       WHERE identity_id = :'runtime_identity_uuid'::uuid) = 1
THEN 'BETUFU_RUNTIME_SQL_OK'
ELSE 'BETUFU_RUNTIME_SQL_FAIL'
END;
BETUFU_SQL
'@
  $postgresProofInput = $postgresProofInput -replace "`r`n?", "`n"
  $postgresProofInput = $postgresProofInput.Replace(
    '__BETUFU_RUNTIME_UUID__',
    $betufuRuntimeIdentityUuid
  )
  $postgresProof = Invoke-BetufuProcess -FilePath $dockerPath `
    -ArgumentList @('container', 'exec', '-i', $initialSnapshots['postgres'].Id, 'sh', '-e') `
    -TimeoutMilliseconds 30000 -StandardInput $postgresProofInput
  Assert-BetufuExitZero -Result $postgresProof -Label 'Prova SQL runtime'
  if ($postgresProof.Stderr -cne '' -or
      $postgresProof.Stdout.Trim() -cne 'BETUFU_RUNTIME_SQL_OK') {
    throw 'Prova SQL runtime não retornou a sentinela exata esperada.'
  }
} catch {
  $primaryFailure = $_.Exception
} finally {
  for ($index = $servicesStartedByBlock.Count - 1; $index -ge 0; $index--) {
    $service = $servicesStartedByBlock[$index]
    try {
      $current = Get-BetufuServiceSnapshot -Service $service
      $initial = $initialSnapshots[$service]
      if ($current.Id -cne $initial.Id -or $current.Image -cne $initial.Image) {
        throw 'ID ou imagem mudou; stop automático recusado.'
      }
      if ($current.State -eq 'running') {
        $expectedStartedAt = $null
        if ($startedSnapshots.ContainsKey($service)) {
          $expectedStartedAt = $startedSnapshots[$service].StartedAt
        } elseif ($startAttempts.ContainsKey($service)) {
          $currentStartedAt = [DateTimeOffset]::Parse($current.StartedAt)
          if ($currentStartedAt -lt $startAttempts[$service]) {
            throw 'StartedAt não pertence à janela da tentativa.'
          }
          $expectedStartedAt = $current.StartedAt
        }
        if ($null -eq $expectedStartedAt -or
            $current.StartedAt -cne $expectedStartedAt) {
          throw 'Serviço está running sem ownership temporal comprovado.'
        }
        $stopResult = Invoke-BetufuProcess -FilePath $dockerPath `
          -ArgumentList @('container', 'stop', '--time', '30', $current.Id) `
          -TimeoutMilliseconds 60000
        Assert-BetufuExitZero -Result $stopResult -Label ('Stop ' + $service)
      } elseif ($current.State -eq 'exited') {
        if ($startedSnapshots.ContainsKey($service)) {
          if ($current.StartedAt -cne $startedSnapshots[$service].StartedAt) {
            throw 'Serviço exited possui fingerprint concorrente.'
          }
        } elseif ($startAttempts.ContainsKey($service)) {
          $currentStartedAt = [DateTimeOffset]::Parse($current.StartedAt)
          if ($currentStartedAt -lt $startAttempts[$service]) {
            throw 'Serviço exited não pertence à janela da tentativa.'
          }
          $startedSnapshots[$service] = $current
        } else {
          throw 'Serviço exited sem ownership atribuível.'
        }
      } else {
        throw ('Estado inesperado durante cleanup: ' + $current.State + '.')
      }
    } catch {
      $cleanupFailures.Add($service)
    }
  }

  foreach ($service in $targetServices) {
    try {
      $final = Get-BetufuServiceSnapshot -Service $service
      $initial = $initialSnapshots[$service]
      $expectedFinalStartedAt = if ($initial.State -eq 'running') {
        $initial.StartedAt
      } elseif ($startedSnapshots.ContainsKey($service)) {
        $startedSnapshots[$service].StartedAt
      } else {
        $initial.StartedAt
      }
      if ($final.Id -cne $initial.Id -or
          $final.Image -cne $initial.Image -or
          $final.State -cne $initial.State -or
          $final.StartedAt -cne $expectedFinalStartedAt) {
        throw 'Snapshot final divergiu do estado inicial.'
      }
      $finalSnapshots[$service] = $final
    } catch {
      if (-not $cleanupFailures.Contains($service)) {
        $cleanupFailures.Add($service)
      }
    }
  }
  try {
    $runtimeLock.Dispose()
    Remove-Item -LiteralPath $runtimeLockPath -Force -ErrorAction Stop
  } catch {
    $cleanupFailures.Add('runtime-lock')
  }
}

if ($cleanupFailures.Count -ne 0) {
  $primaryMarker = if ($null -eq $primaryFailure) { 'absent' } else { 'present' }
  $cleanupMarker = (($cleanupFailures | Sort-Object -Unique) -join ',')
  $runtimeMarker = if ($null -eq $betufuRuntimeFailureMarker) {
    'absent'
  } else {
    $betufuRuntimeFailureMarker
  }
  throw ('RUNTIME_EXECUTION_FAILED: primary=' + $primaryMarker +
    '; cleanup=' + $cleanupMarker + '; runtime=' + $runtimeMarker + '.')
}
if ($null -ne $primaryFailure) {
  $runtimeMarker = if ($null -eq $betufuRuntimeFailureMarker) {
    'absent'
  } else {
    $betufuRuntimeFailureMarker
  }
  throw ('RUNTIME_EXECUTION_FAILED: primary=present; cleanup=none; runtime=' +
    $runtimeMarker + '.')
}

$serviceEvidence = @(
  foreach ($service in $targetServices) {
    [ordered]@{
      service = $service
      id = $initialSnapshots[$service].Id
      image = $initialSnapshots[$service].Image
      initialState = $initialSnapshots[$service].State
      initialStartedAt = $initialSnapshots[$service].StartedAt
      finalState = $finalSnapshots[$service].State
      finalStartedAt = $finalSnapshots[$service].StartedAt
    }
  }
)
$aggregateEvidence = [ordered]@{
  status = 'ok'
  commands = $betufuCommandExitCodes
  runtime = $betufuRuntimeEvidence
  sql = 'BETUFU_RUNTIME_SQL_OK'
  services = $serviceEvidence
  cleanup = 'restored'
}
[Console]::Out.WriteLine(($aggregateEvidence | ConvertTo-Json -Depth 12 -Compress))
```

Como o executor usa somente `docker container start|inspect|exec|stop` sobre IDs já congelados, ele não possui caminho de pull, build, criação ou recriação. O polling restrito do quinto campo `Health` limita a espera a 600 segundos por serviço e respeita PostgreSQL antes de Keycloak. Redis, SeaweedFS e Mailpit não são iniciados. O runner adquire, antes de Java/proxy, uma sentinela TCP exclusiva em `127.0.0.1:6379`; porta ocupada aborta, e qualquer conexão recebida durante a vida do backend reprova. Isso substitui definitivamente a falsa inferência baseada apenas na ausência de nomes `REDIS` no ambiente.

O stdout do runner é exatamente uma linha JSON sanitizada e nenhum log humano adicional; erros vão para stderr já sanitizado. Em falha, o executor não ecoa esse canal: exige uma única linha, limita seu tamanho, valida prefixo, regra `RUNTIME_*` e alfabeto da mensagem e só então incorpora esse marcador ao erro agregado; stderr ausente, multiline ou fora da allowlist permanece oculto e produz `runtime=absent`. O UUID vem do campo `identityUuid`, casa com ambos os corpos HTTP e não é inferido de linha arbitrária do log. O `PASS` de PostgreSQL 18/app-role/Flyway V1/JPA validate exige a conjunção: backend dev iniciou com `ddl-auto=validate`, os dois PUTs persistiram/convergiram e a sentinela SQL confirmou servidor, database, role, histórico Flyway e linha. Porta 5432 aberta, liveness ou log isolado são insuficientes.

O runner limita sua inspeção de exposição a URL, body e cookie observáveis no HTTP; DOM e Web Storage permanecem para o Playwright do 01-21. Ele exige o cookie ativo A, a sequência tombstone(A)→B na resposta canônica do callback OAuth2 e a continuidade de B sem nova emissão no liveness, além dos redirects sensíveis seguros descritos na Task 2, inclusive callback de sucesso sem parâmetros de erro e `/login?error` como terminal fail-closed. Cookies `Secure` permanecem marcados como tal e só são transportados em HTTPS ou nas duas origens HTTP `localhost` exatas aprovadas; partição por origem, host e path continua obrigatória. Todos os subprocessos, requests, sockets e fechamentos possuem timeout dentro de um deadline global. Em sucesso, falha, `SIGINT` ou `SIGTERM`, o cleanup idempotente fecha em ordem reversa apenas sentinela/proxy/backend próprios, preserva causa/sinal e reprova se algum recurso próprio persistir. O `finally` externo restaura somente PostgreSQL/Keycloak iniciados pelo bloco. Se o wrapper externo precisar matar o Node após o deadline interno, o bloco nunca declara `PASS`; portas/processos ambíguos exigem diagnóstico e autorização separados, nunca kill por nome.

#### Diagnostico e correcao do perfil tecnico

A tentativa diagnostica autorizada do Checkpoint F terminou fail-closed no salto sanitizado `keycloak-authenticate` para `keycloak-login-action-other`, com metodo `POST` e status `302`.
