## Auditoria bloqueante do lockfile

Uma execução futura, com autorização própria, poderá criar o scaffold sem instalar pacotes e resolver apenas o lockfile:

```powershell
npm --prefix frontend install --package-lock-only --ignore-scripts
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
```

Antes de aprovar globalmente este Gate, a auditoria deverá comprovar:

1. `package.json` contém exatamente as 14 versões diretas aprovadas, sem faixas;
2. `package-lock.json` é compatível com npm `10.9.8`, repete os pins diretos e não referencia registro, Git, arquivo ou URL fora de `https://registry.npmjs.org/`;
3. toda entrada baixável possui integridade, e as 14 entradas diretas coincidem com os SHA-512 desta Matriz A;
4. o grafo não possui peer dependency ausente/inválida nem pacote direto inesperado;
5. cada entrada com `hasInstallScript` é identificada e revisada; a allowlist exata é registrada em `approved_install_script_packages` e nenhuma entrada inesperada é aceita;
6. `npm --prefix frontend audit --audit-level=high` não encontra advisory high/critical;
7. o diff completo de `package.json` e `package-lock.json` é apresentado ao responsável.

Qualquer alteração de pacote ou versão direta exige uma nova decisão humana; não é permitido “corrigir” silenciosamente a matriz durante a resolução.

### Validador estático obrigatório

O bloco PowerShell 5.1/Node abaixo é a prova executável mínima dos itens 1–6. Ele usa a própria tabela aprovada deste Gate como autoridade, valida `package.json` e lockfile v3 e exige o registro npm oficial e SHA-512 em toda entrada baixável. Enquanto o Gate está pendente, ele inventaria `hasInstallScript` sem encerrar cedo, permitindo que peers e vulnerabilidades também sejam auditados. Depois do fechamento global, o mesmo bloco exige correspondência exata com `approved_install_script_packages` antes de qualquer `npm ci`.

```powershell
@'
const fs = require('node:fs');
const gatePath = '.planning/phases/01-funda-o-segura-da-plataforma/01-04-GATE.md';
const gate = fs.readFileSync(gatePath, 'utf8');
const packageJson = JSON.parse(fs.readFileSync('frontend/package.json', 'utf8'));
const lock = JSON.parse(fs.readFileSync('frontend/package-lock.json', 'utf8'));
const fail = message => { throw new Error(message); };
const gateApproved = /^status: approved$/m.test(gate);
const allowlistStatus = gate.match(/^install_script_allowlist_status: (pending|approved)$/m)?.[1];
const allowlistSource = gate.match(/^approved_install_script_packages: (\[[^\r\n]*\])$/m)?.[1];
if (!allowlistStatus || !allowlistSource) fail('estado da allowlist de install scripts ausente');
const approvedInstallScripts = JSON.parse(allowlistSource);
if (!Array.isArray(approvedInstallScripts) || approvedInstallScripts.some(item => typeof item !== 'string')) fail('allowlist de install scripts invalida');
const rows = [...gate.matchAll(/^\| `([^`]+)` \| (runtime|desenvolvimento) \| `([^`]+)` \| [^|]+ \| \d+ \| `(sha512-[^`]+)` \|$/gm)];
if (rows.length !== 14) fail(`Matriz A deveria ter 14 linhas; obteve ${rows.length}`);
const expected = new Map(rows.map(([, name, group, version, integrity]) => [name, { group, version, integrity }]));
const runtime = Object.fromEntries([...expected].filter(([, item]) => item.group === 'runtime').map(([name, item]) => [name, item.version]));
const development = Object.fromEntries([...expected].filter(([, item]) => item.group === 'desenvolvimento').map(([name, item]) => [name, item.version]));
const sameObject = (actual, wanted) => JSON.stringify(Object.entries(actual || {}).sort()) === JSON.stringify(Object.entries(wanted).sort());
if (!sameObject(packageJson.dependencies, runtime)) fail('dependencies diverge da Matriz A');
if (!sameObject(packageJson.devDependencies, development)) fail('devDependencies diverge da Matriz A');
if (lock.lockfileVersion !== 3) fail(`lockfileVersion inesperado: ${lock.lockfileVersion}`);
const root = lock.packages && lock.packages[''];
if (!root) fail('entrada raiz packages[""] ausente');
if (!sameObject(root.dependencies, runtime)) fail('pins runtime da raiz do lock divergem');
if (!sameObject(root.devDependencies, development)) fail('pins dev da raiz do lock divergem');
for (const [name, item] of expected) {
  const entry = lock.packages[`node_modules/${name}`];
  if (!entry) fail(`entrada direta ausente: ${name}`);
  if (entry.version !== item.version) fail(`versao direta divergente: ${name}`);
  if (entry.integrity !== item.integrity) fail(`integridade direta divergente: ${name}`);
}
const installScripts = [];
for (const [path, entry] of Object.entries(lock.packages || {})) {
  if (entry.resolved) {
    if (!entry.resolved.startsWith('https://registry.npmjs.org/')) fail(`origem nao aprovada: ${path}`);
    if (!/^sha512-/.test(entry.integrity || '')) fail(`SHA-512 ausente: ${path}`);
  }
  if (entry.hasInstallScript) installScripts.push(path);
}
installScripts.sort();
approvedInstallScripts.sort();
console.log(`INFO hasInstallScript (${installScripts.length}):\n${installScripts.join('\n') || '(nenhum)'}`);
if (gateApproved) {
  if (allowlistStatus !== 'approved') fail('Gate aprovado sem allowlist aprovada');
  if (JSON.stringify(installScripts) !== JSON.stringify(approvedInstallScripts)) fail('hasInstallScript diverge da allowlist aprovada');
  console.log('PASS: allowlist de install scripts corresponde exatamente ao lock aprovado.');
} else {
  if (allowlistStatus !== 'pending') fail('Gate pending com allowlist marcada como approved');
  console.log('PENDING: revisar a lista e registrar a allowlist antes de fechar o Gate.');
}
console.log(`PASS: ${expected.size} diretas e ${Object.keys(lock.packages).length - 1} entradas de lock validadas.`);
'@ | node
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

npm --prefix frontend ls --all --package-lock-only
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

npm --prefix frontend audit --audit-level=high
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
```
