# Plan 05.1-01 Summary

Connected the published sports-event journey to the existing anonymous odds
market without introducing a `sports` to `odds` internal dependency.

## Delivered

- `PublicEventDetail` now exposes an optional, nullable `marketId` only when
  exactly one market for the event is accepted by the existing public odds
  projection.
- The `sports` module owns the minimal `PublicEventMarketLookup` consumer port;
  the `odds.internal.publicview` adapter implements it using the established
  public-market read model. Zero, ambiguous or non-public markets fail closed.
- The public event page renders a discoverable `Ver odds da partida` Angular
  link when the reference exists and renders no odds promise otherwise.
- The OpenAPI YAML remains the source of truth. The generated Angular model was
  regenerated by the governed runner and now types `marketId?: string | null`.
- Backend and frontend regressions cover the public JSON field, absence without
  a market, Modulith exposure, generated contract and CTA presence/absence.
