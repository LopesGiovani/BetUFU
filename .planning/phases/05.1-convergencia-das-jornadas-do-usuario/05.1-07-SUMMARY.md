# Plan 05.1-07 Summary

Certified the converged user journeys against the real local BETUFU stack with
an anti-mock Playwright suite and complete repository gates.

## Delivered

- Added a serial real-browser suite that discovers odds from visible Arena and
  event links instead of using a known UUID.
- Exercised contextual Keycloak login and return to the original market, the
  authenticated Arena shell, real credit balance, active enrollment profile,
  isolated browser contexts, deadline precedence, browser history, refresh,
  protected-route return and accessible 404 recovery.
- Added Chromium and Firefox projects for desktop and 320 px with retries zero,
  one worker and traces/screenshots/videos disabled.
- Added a source validator and five mutation-style unit tests that reject
  business API interception, injected auth, literal UUIDs, literal credentials
  and missing integrated journey markers.
- Reconciled the isolated identity module fixture with the public
  `ProfileEnrollmentStatusLookup` port introduced in Plan 05.1-04.

## Evidence Boundaries

- The suite uses real Keycloak UI, backend, PostgreSQL-backed projections,
  enrollment, credits and odds; it does not mock `/api/v1/**` or inject auth.
- The client clock is fixed to the approved seed instant for deterministic
  discovery and deadline testing. Server-side authorities remain unchanged.
- Phase 5's certified browser/backend evidence remains authoritative for
  prediction creation, receipt recovery and duplicate rejection. This plan did
  not create another debit or reset the local fixture.

## Deviations From Plan

- On Windows, the Playwright config required the repository-relative path
  `frontend/playwright.user-journeys.config.ts` despite `npm --prefix frontend`.
- The suite used the existing Playwright Firefox cache revision 1543 because
  the configured revision was absent; no external download occurred.
- One final run exposed a race where the Arena heading preceded asynchronous
  event links. Waiting for the first visible event link removed the timing
  assumption, and the clean repetition passed 12/12.
- The aggregate Maven suite required a Mockito bean for
  `ProfileEnrollmentStatusLookup` in `IdentityModuleTest`. This is a mechanical
  fixture correction; production code and module boundaries did not change.
- The local backend container initially used an older packaged JAR. Rebuilding
  the approved local artifact and restarting the already-authorized full stack
  aligned the runtime with the checkout without reset or seed.
