## Phase boundary and invariants

Esta fase entrega mercados simples de confronto direto antes do jogo e odds automaticas, explicaveis e versionadas. Um administrador com o escopo correto pode abrir e governar o mercado; qualquer visitante pode consultar a odd atual, o historico, a metodologia, as entradas e o nivel de confianca. O preco nasce de um modelo esportivo reproduzivel (Elo, com tratamento explicito de empate quando o regulamento permitir) e de uma margem configuravel, sem depender do volume de palpites.

O dominio continua generico para varias competicoes, edicoes, modalidades e categorias, mas a operacao detalhada fica restrita a eventos HEAD_TO_HEAD. Creditos, apostas, liquidacao, mercados multi-competidor, estatisticas especificas e uso recorrente do extrator LAUFU nao pertencem a estes planos. ## Trust Boundaries (ASVS Level 1; high-severity findings block release)

| Boundary | What crosses it | Required control |
|---|---|---|
| sports -> odds | event scope, participants, canonical instant and confirmed result | approved public port/event; no `sports.internal`; exact `confirmedVersionId` |
| operator/browser -> odds API | IDs, states, prices, evidence and commands | server-side persisted scope, validation, CSRF and Problem Details |
| odds service -> PostgreSQL | model facts, lifecycle, override and audit rows | transaction, locks, idempotency, constraints and append-only triggers |
| OpenAPI -> Angular | public/admin schemas and generated code | candidate inventory/digest, human approval and official generator |
| LAUFU/sample -> calibration | external rows and identities | provenance/digest, quarantine, no production dependency |

| Threat ID | STRIDE | Component | Severity | Disposition | Mitigation |
|---|---|---|---|---|---|
| T-04-CALIBRATION | Tampering | dataset, formulas and fixtures | high | mitigate | temporal split, SHA-256 provenance, golden vectors and blocking approval (04-01) |
| T-04-MODULE | Elevation/tampering | sports/odds boundary | high | mitigate | ArchUnit/Modulith rule forbids `sports.internal` imports and reverse cycle (04-02, 04-08) |
| T-04-TAXONOMY | Tampering | W.O./cancel/abandon mapping | high | mitigate | explicit result-kind contract, no numeric W.O. inference, negative fixtures (04-02, 04-04) |
| T-04-SCOPE | Elevation of privilege | create/suspend/override commands | high | mitigate | derive competition from persisted resource; two-scope 403/no-write tests (04-05, 04-06) |
| T-04-RACE | Tampering/repudiation | close, suspend, approve and publish | high | mitigate | row lock or optimistic version, idempotency and concurrency IT (04-09, 04-06) |
| T-04-REWRITE | Tampering | prices, calculations, lifecycle and audit | high | mitigate | database privileges/triggers reject UPDATE/DELETE; lineage inserts new facts (04-09, 04-08) |
| T-04-SELF-APPROVAL | Repudiation/elevation | override maker-checker | high | mitigate | distinct persisted actors, same-actor 403/409 and atomic audit (04-06) |

| T-04-VOLUME | Tampering | pricing inputs | high | mitigate | pure kernel input type excludes betting modules; mutation proving output independence (04-04) |
| T-04-LAUFU | Spoofing/tampering | exploratory extractor | high | mitigate | do not execute/promote scraper; quarantine unresolved identities and require digest (04-01, 04-08) |
| T-04-SUPPLY-CHAIN | Tampering | package/dependency installation | high | mitigate | no new packages; if a need appears, stop for package-legitimacy and owner checkpoint |
